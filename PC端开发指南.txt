====================================================
垂钓社区 App（fishing_app）· 电脑端开发指南
====================================================
Flutter 项目，一套代码可构建 Android / iOS 双端 App。
本指南教你把它跑起来、改代码、打包。

----------------------------------------------------
一、电脑需要装什么（一次性，约 30 分钟）
----------------------------------------------------
1. Flutter SDK（版本要求 3.16 以上，推荐 3.24.x）
   官网：https://docs.flutter.dev/get-started/install
   Windows 下载 zip 解压后，把 flutter\bin 加进系统 Path。
   装完在命令行执行：flutter doctor
   （按提示把缺的项补齐，主要是 Android Studio）

2. Android Studio（提供安卓模拟器和 SDK）
   官网：https://developer.android.com/studio
   安装时勾选 Android SDK。装完 flutter doctor 全打勾即可。

3. （可选，二选一）VS Code + Flutter 插件 —— 更轻量，适合写代码
   Android Studio 功能全，VS Code 更轻。新手推荐 Android Studio。

----------------------------------------------------
二、打开项目并跑起来
----------------------------------------------------
1. 解压本压缩包，得到 fishing_app 文件夹
2. 用 Android Studio：File → Open → 选 fishing_app 文件夹
   （或 VS Code：File → Open Folder）
3.首次打开会自动执行 flutter pub get 下载依赖
   （约 1-3 分钟，需要联网）
4. 插上手机（开 USB 调试）或打开安卓模拟器
5. 点运行按钮 ▶，或命令行执行：
   flutter run
   App 就装在手机/模拟器上了，改代码后按 r 热重载。

三、代码结构（改哪里）
----------------------------------------------------
lib/

├── app_theme.dart             主题配色

----------------------------------------------------
四、常用命令（在项目目录打开命令行）
----------------------------------------------------
flutter pub get              下载/更新依赖
flutter run                  连接到设备运行（调试）
flutter build apk --release  打安卓安装包
  → 产物在 build/app/outputs/flutter-apk/app-release.apk
flutter clean                清理构建缓存（遇到诡异报错先跑这个）

----------------------------------------------------
五、改后端接口地址
----------------------------------------------------
打开 lib/services/api_config.dart，改这一行：
  static const String baseUrl = 'http://106.54.193.199:8801/api';
换成你的服务器地址即可（以 /api 结尾，不要末尾斜杠）。
改完重新 build apk。

----------------------------------------------------
六、打包签名（已配置好，直接用）
----------------------------------------------------
android/fishing.keystore   签名密钥（已放进项目）
android/key.properties     签名密码配置
发布包会自动用这个密钥签名，和官方包签名一致，
用户覆盖安装不会冲突。
⚠️ 这个密钥文件要妥善保管，别弄丢：
   以后更新 App 必须用同一个密钥签名，否则老用户无法覆盖安装。

----------------------------------------------------
七、注意事项
----------------------------------------------------
1. api_client.dart 里发 JSON 必须用：
   req.add(utf8.encode(jsonEncode(data)))
   不要改成 req.write(jsonEncode(data))——那是 UTF-8 编码 bug，
   中文昵称/内容会直接报错（已修复，别回退）。
2. iOS 打包需要 macOS + Xcode，Windows 上只能打安卓包。
3. 第一次 flutter pub get 失败，多半是网络：
   可设置国内镜像再试（搜索 "flutter pub 镜像"）。
4. 报错先试 flutter clean && flutter pub get，能解决大半问题。
